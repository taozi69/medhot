## 三、功能实现

### 1. 医疗分类体系（taxonomy.ts）
- **13 个类别**：临床 clinical / 科研 research / 医学教育 edu / 药品 drug / 器械 device / 医疗AI medai / 政策监管 policy / 医院医保 hospital / 公共卫生 pubhealth / 国际医疗 intl / 医药产业 industry / 科普 tip / 综合 general
- 第一个 `key: "industry"` 的类别在"医药产业与资本"节 → 日报未归类条目回退到此节（`reports/compose.ts` 契约）
- **主题标签**（20 专科 + 18 内容类型）：心血管、肿瘤、神经、呼吸、消化、感染、内分泌、血液、肾脏、儿科、妇产、急诊、重症、骨科、眼科、皮肤、麻醉、检验、影像、病理 + 政策发布、临床试验、随机对照试验、Meta分析、观察性研究、注册审批、药品上市、药品撤市、集采、医保、医疗器械、AI产品、医院改革、投融资并购、公共卫生事件、国际动态、科普、评论
- **实体标签**（22 个）：NMPA、FDA、EMA、国家卫健委、国家医保局、中国CDC、WHO、NEJM、The Lancet、BMJ、JAMA + 辉瑞、默沙东、诺华、阿斯利康、百济神州、恒瑞医药、药明康德、迈瑞医疗、联影、腾讯医疗、百度健康
- **标签兜底** = CATEGORY_TAGS 最后一项"其他"（`vocabulary.ts` 契约）
- ITEM_TYPES 7 类：regulatory_action / clinical_study / research_paper / market_event / industry_event / opinion_analysis / tutorial_explainer

### 2. 信源种子（sources.json，12 个）
| 信源 | tier | kind |
|---|---|---|
| NEJM / The Lancet / Nature Medicine / Nature Reviews Cancer / arXiv q-bio.MN | T2 | rss |
| STAT 主站 / STAT 医药 / Endpoints | T2 | rss |
| MedTech Dive / BioPharma Dive / Drug Discovery & Development | T2 | rss |
| 国家医保局·政策解读 | T1 | web_list |

- 全部通过 `assertSupportedConfig`（config-keys.ts）与 `SeedSource` 行级字段校验
- NMPA / 国家卫健委（JS 反爬）、FDA / EMA（无官方 RSS）未入种子，`$comment` 注明后台补法

### 3. 精选门槛（selection.ts）
- T1=60 / T1.5=65 / T2=76，内容理解底线 50
- 评分链：`tierThreshold(tier)` → 2 次独立 LLM 打分（`SCORE_CALLS=2`）→ `sum ≥ 2×threshold` 进精选 → 平均分（向下取整）展示（`editorial/analyze.ts` 核实）

### 4. 医疗评分模型（selection-score.md）
- 仍输出**单字段 `attentionScore`**（`ScoreSchema` 严格校验，双轨评分属 B 档）
- 内部五轴（sig 实质份量 / nov 信息增量 / cred 证据强度 / reson 共振面 / act 可用性）× 7 类内容权重表
- **证据等级硬约束**：动物≠人体、体外≠临床有效、观察性≠RCT、I/II/III 期不相混、受理≠获批、预印本≠同行评审、撤市≠召回——夸大标题按实际等级降分
- 11 条压噪规则：企业通稿、动物/体外、单病例、营销软文、例行小版本等强制 sig/cred 封顶

### 5. 医疗安全体系（rules-domain + safety + rules-anti-hallucination）
- 安全十条（不把相关性写成因果 / 动物实验≠人体疗效 / 体外≠临床有效 / 观察性≠RCT / 早期临床≠已证实 / 企业宣传≠医学结论 / 候选药物≠已上市 / 预印本≠正式论文 / 指南≠法律 / 单病例≠普遍规律 / 标题≠临床结论）
- 信息五层：事实 / 来源原文观点 / AI 总结 / AI 推断 / 专业解释
- 医疗术语表：Trial→临床试验、Endpoint→终点、Cohort→队列、Black Box→黑框警告等歧义词按医疗含义；NMPA/FDA/NEJM/KEYNOTE-389/HR/p 值/剂量单位一律保留原文

### 6. 事件聚簇（group 系列 5 个提示词）
- 医疗硬规则：同一药"受理/申报中/获批/撤市"是不同发生，**不得**归 SAME_OCCURRENCE；同一试验 I 期与 III 期结果同理
- 聚簇链（`events/group.ts`/`relate.ts`）：手动决定 > 历史归档 > signal 归组 > 成员保留 > LLM 判定

### 7. 提示词（27 个医疗版）
- 摘要/翻译：保留药名、剂量、期别、HR/p 值/生存率/样本量，阶段词按原文不升级
- 日报导语 / 周报月报 / 事件综述：点出监管动作与阶段，"对谁最相关"
- 内容理解：7 类 itemType 与 taxonomy 的 `CATEGORY_BY_ITEM_TYPE` 映射一致
