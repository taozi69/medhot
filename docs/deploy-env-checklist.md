# MedHOT 重新部署 · .env 核对清单

> 用途：每次在手机 WorkBuddy 里重新部署时，按这份清单确认密钥没丢。
> `.env` **不在 Git 仓库里**，代码重建不会带上它 —— 丢了就得重新填。

---

## 部署前：先备份

在手机 WorkBuddy 的沙箱里找到 `.env`，把**全文复制**出来，存到密码管理器或加密笔记。

原因：你的 `.env` 目前只存在于那台部署机上，本机没有副本。如果云端那份在重建中丢了，就没有第二份可恢复。

⚠️ 备份时**不要**把内容发到聊天窗口 —— 里面全是密钥。

---

## 部署后：逐项核对

打开线上站点 `https://你的域名/admin` 逐项验证。

### 第一组 · 最小可用（这四项缺一个，服务直接起不来）

| 变量 | 作用 | 丢了会怎样 | 怎么验证 |
|---|---|---|---|
| `DATABASE_URL` | 数据库连接 | 启动崩溃 | 信源页能打开、显示 80 个源 |
| `ADMIN_PASSWORD` | 后台密码（≥12 位） | 后台登不进去 | 能正常登录 |
| `SESSION_SECRET` | 会话签名 | 登录后立刻掉线、反复跳登录页 | 登录后停留几个页面不掉线 |
| `LLM_API_KEY` + `LLM_BASE_URL` + `LLM_MODEL` | 默认模型 | 分析全停，不出新文章 | 运行页能看到新的分析记录 |

> 注：如果用 Docker 部署，还要 `POSTGRES_PASSWORD`（数据库密码）。三个密钥类变量可以用 `openssl rand -hex 32` 生成 —— 但**必须恢复成原来的值**，换新的会导致已登录会话全部失效。

### 第二组 · 你的业务配置

| 变量 | 作用 | 怎么验证 |
|---|---|---|
| `SITE_URL` | 对外域名，生成链接/RSS/分享图都用它 | 分享链接的域名对不对 |
| `LLM_API_N_KEY` / `_BASE_URL` / `_MODEL` / `_MAX_CONCURRENCY` | 多端点池（编号不必连续） | 后台 `/admin/llm-pool` 里端点都在、测速能通 |
| 各家单独的 Key（deepseek / dashscope / zhipu / xiaomi） | 分工模型用的 | 分析成功率正常 |
| `EGRESS_PROXY_URL` | 抓海外信源走代理 | 海外源能正常更新 |
| `IMG_PROXY_SIGN_SECRET` | 图片代理签名 | 文章配图能正常显示 |

### 第三组 · 按实际启用的功能查

| 变量 | 什么时候需要 |
|---|---|
| `FEISHU_*` | 开了飞书推送或飞书登录后台 |
| `SOCIALDATA_API_KEY` | 要监控 X 账号、Codex 重置 |
| `DAJIALA_KEY` | 要抓微信公众号 |
| `JINA_API_KEY` | 需要浏览器渲染兜底抓正文 |
| `GITHUB_TOKEN` | 读 GitHub 类信源 |
| `EMBEDDING_*` / `DASHSCOPE_API_KEY` | 要向量召回让事件归组更准 |
| `INGEST_TOKEN` | 有外部脚本往站里推内容 |
| `DB_BACKUP_*` | 配了数据库自动备份到对象存储 |

> 完整的变量清单和说明在仓库里的 `.env.example`（只有变量名、没有真实值）。

## 给 WorkBuddy 的话（可直接复制）

```
请拉取 taozi69/medhot 的代码重新部署，用 tag medhot-v3.0.0。

重要：
1. 重新部署前先把沙箱里的 .env 完整备份出来，重建后恢复进去。
   .env 不在 Git 仓库里，代码重建不会带上它。
2. 数据库不要动、不要重建 —— 80 个信源和已有文章都存在数据库里。
3. 部署完成后确认三件事：
   - 后台能登录
   - 信源页显示 80 个源
   - 分析功能正常，能出新的文章
```

## 出问题时对照

| 症状 | 最可能的原因 |
|---|---|
| 服务启动就崩、日志报连不上数据库 | `DATABASE_URL` 丢了 |
| 能打开页面但登不进后台 | `ADMIN_PASSWORD` 丢了 |
| 登录后立刻被弹回登录页 | `SESSION_SECRET` 变了或丢了 |
| 能登录、无报错，但一直没有新文章 | `LLM_API_KEY` 丢了或失效 |
| 后台信源页是空的 / 只有很少几个 | 连到了空数据库，或没跑 seed |
| 图片全部裂开 | `IMG_PROXY_SIGN_SECRET` 丢了 |
| 海外信源一直不更新 | `EGRESS_PROXY_URL` 丢了 |
