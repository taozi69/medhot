
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：药名 / 器械名 / 机构名 / 企业名 / 试验方案名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是代号 / 没信息量的 teaser（如 "NCT05819675"、"Black Box"、"获批"、"重磅公告"）时，结合【来源】和正文把主体补进标题。例：原标题 "NCT05819675 results" + 来源 "NEJM" → "KEYNOTE-389 III 期结果：某药联合某药用于某癌"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体药名/器械时，用上位词（如"某 PD-1 抑制剂""某国产核磁共振设备"）兜底，绝不凭"行业常识"编一个具体型号/数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / Benchmark 这类解释、分析、教程或评测标题，中文标题必须保留这个类型；不能因为正文谈到一个已批准药、器械或新数据，就改写成"获批/上市/撤市"。只有原标题明确宣布了监管动作，中文标题才能使用对应阶段词。
   例：原标题 "How checkpoint inhibitors reshape oncology" → "免疫检查点抑制剂如何重塑肿瘤治疗"，不能写成"某药获批用于肿瘤"。
6. 标题里的阶段词必须与原文一致：受理 / 申报中 / 获批 / 上市 / 撤市 / 召回 / I/II/III 期结果，不得升级或降级。
